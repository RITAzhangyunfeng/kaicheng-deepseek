1. 韩宝林人设与叙事方式

1.1 自我定位（人设脚本 + 30岁 + 话术）

  • 家族传承 + 第三代："我们家祖辈都是做人参的,到我这已经是第三代了""从小就跟着长辈们在森山里干活""毕业后直接参与了高丽参的销售业务,在20多年的销售过程中掌握了更多专业知识"。→ 立"世家传人"的信任根基。
  • 专业判断权威："什么东西是好参,我是最懂的""什么样的高丽参好,我是最懂的"——把"会挑/懂行"作为核心人设资产,而非品牌光环。
  • 创业苦情叙事的翻转：人设脚本开头"听不懂！不相信！没人脉！四处碰壁！"→ 刚来南方时的狼狈 → 20 多年坚持 → "如今全国合作门店数量已达 2 万家以上,也注册了自己的开成高俪品牌,自主种植、加工、销售"。用"底层逆袭"换共情与信任。
  • 总代理背书："我们的产品是朝鲜开城牌高丽参,大中华区总代理"（QA 中亦称"代理过朝鲜开城高丽参20年之久","朝鲜开城参是公认的国宝级别"）。
  • 谦逊 + 接力棒叙事：30年陈老参"是父辈们辛辛苦苦传下来的,我不敢占为己有,我只是想通过这样一个平台把它很好地呈现给大家,做好我这一代人的接力棒"。→ 把"老货"解释成祖业传承,顺势化解"30年参为何在你手里"的质疑,还抬高稀缺性。
  • "同行不讲、我讲"的差异化："这些是我直播间才会听到的,其他直播间都不会跟你讲"（如不规则参的缺点、磨粉猫腻、山东文登参冒充等）——主动"拆台同行"来建立"只有我说真话"的形象。

1.2 常用话术结构（三段式 / 信任-判断-退路）

从《高丽参话术》看完整直播流程为 6 段：开场互动 → 产品价值塑造 → 价格机制 → 适宜人群 → 送礼价值 → 打消疑虑。逐段的心法：

  1. 先立信任/专业："这里是高丽参源头直播间,今天我们来了解什么才是真正高品质的高丽参"。先给身份（源头工厂、两家大型饮片厂）和"我是来教你判断的"。
  2. 教判断标准 / 给方法论：反复用"一看种植年份、二看加工工艺、三看陈化时间""看芦碗数+2=年根""看颜色红棕色/深红棕色、有菊花纹""闻、看、尝、泡"等内容,把购买决策拆成"可验证的公开标准",让用户觉得自己学会了,从而信你卖的是对的。
  3. 给退路 / 打消疑虑："不喜欢能不能退？可以退,7天无理由退货""运费险也都给安排上了""正品保障假一罚四""下单后可以免费切片或打粉""吃不完怎么保存都教你"。——用售后承诺降低决策压力。
  4. 价格机制"锚定 + 让利"："线下专柜 3298,现在下单到手价只要 1679""送出去就是3、4千的牌面"；用新会陈皮（5年100多块 vs 30年上万)和茅台（陈30年酱香更浓)做类比,把"30年老 + 贵"合理化,再把"源头批发价"作为让利理由。
  5. 场景化 + 送礼叙事："过年送领导送客户,往年买烟买酒…但人参不一样,人'生'如意,事事如意,顺风又顺水""送礼送得好,客户跑不了""送人送礼送健康"。

1.3 口播语言风格

  • 大量口语、重复、即时互动（"家人们、宝贝们""明白吗？""看到吗？""来我直播间,赶紧""扣个已拍"）。
  • 用对比、类比、数字（"46根""1克¥1.75""4.8到5.0""10遍不糊烂"）增强可信度与冲击。
  • 会用"拆同行"制造戏剧冲突（其他直播间的坑、磨粉猫腻、冒充等）。
  • 语音转写错误较多（如"慈禧/声波/登朱莉/中职生/美国外交上"等），原稿应为方言/口播转写,提取时已尽量还原语义。

4. 高丽参 QA 要点（直播间高频问题 → 标准回答）

来源：高丽参QA(韩宝林已修改)(1).docx,共 39 条。逐一浓缩：

4.1 用法与用量

  • 冲泡法：切片开水冲泡,每天3克（3-4片）；每周2-3次则每次5-6克;可反复泡至无颜色后吃掉。
  • 人参蜜饯：切片/打粉用蜂蜜浸泡,罐装冰箱冷藏,每天早晨空腹1勺、睡前2小时前1勺。
  • 炖汤：1根即可（切片、切段、整根均可）。
  • 泡酒：10斤酒——60规格4-5根、30-40规格3-4根、20规格2-3根、10-15规格1根。

4.2 品级 / 价格 / 规格

  • 2999元＝天级20支600克装（芦头大、参体参腿完整、切片率高、每片有花纹、冲泡次数多、气味浓香、营养更多吸收完全）——精品、级别高。
  • 1999元＝良级20支600克装（外观稍逊,但内在营养同样38种以上,适合自用泡茶或接待）。
  • 549元＝天级40支300克装（参型较小,但营养、口感、冲泡次数、气味都达高水准,适合煲汤泡酒）。
  • 549 / 749 / 2999 区别：都是老货,区别在规格大小与品级,规格越大营养价值越高、参香越浓、越耐泡、越有收藏价值、市场越难买。
  • 20支为什么是28条：高丽参按司马斤计算——15支=600克19条、20支=600克28条、30支=38条、40支=48条、50支=58条、60支=68条、70支=78条。
  • 20支每条克重：18-24克,一般20克（600克/28≈21.4,最小18克、最大24克）。

4.3 营养 / 功效 / 适合人群（⚠️ 功效表述多为合规改写点）

  • 营养成分：多种人参皂甙、皂苷38种以上（RH2对术后恢复有帮助）、人参多糖、人参蛋白、生物碱、脂溶成分（脂肪酸、精油）、糖类（单糖、低聚糖、多糖果胶）、维生素。
  • 吃的好处（原文）：增强免疫力、补元气、抗疲劳、抗衰老、改善记忆力、调节血糖、保护心脑血管、改善睡眠。（全部属医疗/保健功效,写内容时需按第5节改写。）
  • 适合人群：气虚（气短、盗汗、乏力）、阳虚（怕冷、腰膝酸软）、免疫力低下（易感、易疲劳）、记忆力减退、劳动/用脑强度大、日常滋补保养。年龄大者主推"强心"作用。（⚠️ 需改写）
  • 不适合人群：孕妇、哺乳期妇女、14周岁以下儿童、过敏者；感冒期间、经期不宜；严重高血压需在医生指导下服用。
  • 不能和什么一起吃：藜芦、五灵脂（药性相反禁止同服）；不宜与浓茶、咖啡、白萝卜同食。
  • 不是纯野生：所有高丽参（含红参）都用种植鲜参加工,非纯野生；但生长过程无人工干预,产自长白山脉而非农田温室,营养价值不低于野生且更有性价比。

4.4 年份 / 鉴别（最核心的知识点）

  • "6年根 vs 30年"的吵架解释（最高频疑义）："6年根＝种植需6年成熟；30年＝加工完成后陈化储存了30年。比如30年茅台,指酒存了30年,越陈越香。"
  • 会不会变质：不会。高丽参经过洗、蒸、晒杀灭微生物；保存好可长期保存；时间越长营养越多、更易吸收、燥热性更低。
  • 保质期 / 保存：阴凉干燥通风密封可长期保存；室温高于25℃或潮湿需冷藏；切片打粉后冷藏1-2年。
  • 6年根判断：看芦头/芦碗（坑）数量：芦碗数 + 2 = 年根（4碗=6年,3碗=5年）；注意有的碗被挤压成小坑也算一年。＋2 是因为1-2年的参太小太嫩、干燥后形不成芦碗。
  • 花纹不能判断年份：花纹圈数与年根无关。坡地水分少→花纹多；平地水分足→花纹少1-2圈；干浆参（当年未出土、营养不足的死秧）花纹更多2-4圈。
  • 辨别老参四步：①闻——陈年越久气味越浓厚；②看——陈年越久颜色越深成深红棕色,当年新货泛黄；③品尝——老参汤参味浓厚,未陈化的似清草根味；④冲泡——老参泡10遍不糊烂、味如初,未陈化的冲4-5次就没味且易烂。
  • 黄皮是否是老参：黄皮不是老参的指标。黄皮是中国商户过去模仿韩国高丽参黄皮人为晒出（水参表皮晒半干再蒸,营养少）；好参黄皮少；本品用"干燥室+阳光"（蒸后晒,营养不流失）。真正证明老的关键先后看——香气、颜色、参汤味道、冲泡次数,尤其香味。
  • 为什么同规格、同陈化30年颜色和香味不同：①蒸参时蒸屉内区域温度不同——温度高熟透好、皮薄、颜色反映到表面；温度低熟透差、皮黄,但肉质相同,陈化发酵后肉质越来越深。②陈化发酵需温度——陈化室上层温度高、陈化好、香气浓；底层差。

4.5 加工 / 服务 / 售后

  • 切片 / 打粉：提供免费切片或打粉；打粉不支持退换货。
  • 切片为什么晚发货：纯手工切片,需软化→切片→烘干,以保证长期储存,延迟1-2天。
  • 能不能半切半不切：不建议。参足干、封存30年,切片需打湿-切片-烘干,半切会拆开参、破坏品相及芦头参腿完整度。建议全切或发整参。
  • 一根切多少片：60支约14片、30-40支约15-16片、20支约17片,取决于厚度和样式。
  • 自己在家怎切：纱布打湿包好上锅蒸,水开边缘见气计时5-6分钟,趁热切;切片后自然风干,潮湿可用风扇/吹风机。
  • 微波炉/烤箱：不建议,不好控火候,易蜂窝状或烤糊;建议隔水蒸。
  • 毛巾和剪刀用法（赠品）：毛巾浸湿包裹参,蒸5-6分钟(见汽计时)掰开成单根；单根湿润排列湿毛巾上再蒸——天30/40/60支蒸10-11分钟、天15/20支蒸15-16分钟(见汽计时),取出趁热切片,用剪刀更方便。吃几根切几根。
  • 菊花纹不明显的解释：自家参大部分有菊花纹；自己切片受蒸的时间、工具、经验影响；老师傅手工切片也达不到100%,任何厂家都达不到。
  • 子宫肌瘤能吃吗：可以适量吃（补充营养、改善气血虚、缓解不适）。(⚠️ 医疗相关,需谨慎表述)
  • 自己在家加热吃不完怎么保存：用剪刀剪吃多少；剩余放密封袋0-8℃冷藏,第二次直接剪,无需再蒸。

5. 合规红线汇总（重点 · 写内容必须遵守）

用「30年老货高丽参」这一个拳头产品,靠「源头工厂 + 批发价 + 三代传承」讲信任,靠「鉴别标准 + 陈化类比 + 耐泡品质」讲价值,再用「天级/良级/规格」做价格阶梯,覆盖送礼、自用、尝鲜人群;但整条内容链必须以「去医疗功效 + 合规售后承诺 + 客观竞争表达」为前提,否则高价值卖点会被平台限流/封禁拖垮。
