开成高俪《高丽老红参单产品内容作战手册》v0.2

版本说明：本手册是在 v0.1（全网高丽参内容作战手册）基础上，按 2026-08-22 战略决策重构而成的单产品放大总纲。
相对 v0.1 的四个重大变化：
1）从"多线找坡"收窄为"单产品放大"——只做高丽老红参；
2）明确双渠道结构——直营（抖音IP直播间，主力放大）＋ 菜菜分销（只供品，不投入内容）；
3）把内容明确为四类——品牌内容／搜索内容／GEO内容／千川投放素材，对应三大目标（引流／信任／品牌）；
4）明确分工边界——真实世界由用户与韩宝林提供，数字世界由 AI 完成。

使用方式：先读第 0 节一页纸总览，其余章节按需查阅；每条原则与流程可在实际运行中修订，修订注明版本。

0. 一页纸总览

产品：高丽老红参（单产品，不扩产品线）。

使命（不变）：以十年持续叙事为时间尺度，以开成高俪的真实产品、人物、工艺与用户为内容源头，由 AI 主导从需求洞察、内容生产、渠道适配到投放放大的全过程，持续向适用电商平台生产高丽老红参内容；人只负责 AI 无法替代的真实世界与关键判断。

双渠道：

渠道 形态 年规模 定位 内容投入
直营 抖音 IP 直播间（韩宝林）每晚直播 300 万 主力，全力放大 全力投入
分销 菜菜 · 视频号＋小红书直播间 1000 万 分销，可干预空间小 只持续研发产品，不投入内容

商业闭环：内容获客（品牌/搜索/GEO/千川四类）→ 直播成交（韩宝林 IP 直播间）→ 私域/会员复购（终极形态：IP＋会员订阅制）→ 数据反馈 → 迭代。

当前商业判断（单产品版）：以高丽老红参承接"存量红参/高丽参用户换品牌"这条已验证最强的坡（8.5/10）。核心 Job：

给我一支我敢长期吃、每天吃得方便、品质不用反复怀疑的高丽老红参。

其余两个假设的地位见第 1 节。

1. 战略重构：从"找坡"到"放大"

v0.1 的三个假设，在本战略下重新定级：

假设 证据强度 新战略下地位 处理方式
存量红参/高丽参用户换品牌 8.5/10 主攻方向（固化） 全部内容资源围绕它，用高丽老红参承接
30-45岁女性气血"补对" 8/10 降级为内容探针 只作观察方向的内容探针，不做产品、不占主线资源，用于验证/纠偏
30-45岁日常精力管理 5/10 暂缓/待证伪 不投入，保留为候选

拉式逻辑不变：一群人正在强烈解决一个问题 → 已经在花钱 → 现有方案不够好 → 高丽老红参是更好的方案 → 非遗炮制/真年份/陈化/检测让对手抄不走。

关键纪律：不再多点试错。所有内容、投放、直播，都围绕"让已认可红参、正在持续吃参、但对真假/安全/长期怎么吃/方便程度不满的人，相信开成高俪的高丽老红参"这一条主线展开。

2. 渠道结构与投入边界

2.1 直营（主力放大）

  • 载体：抖音 IP 直播间，韩宝林每晚直播。
  • 目标：把 300 万这条主战场做大。四类内容全部围绕"把它喂大"。
  • 内容职责：为直播间送人（引流）、让人相信（信任）、沉淀品牌（品牌）。
  • 放大器：千川素材负责送人进房，直播负责成交，品牌/搜索/GEO负责长期认知与信任。

2.2 菜菜分销（供品边界）

  • 载体：视频号＋小红书直播间，年 1000 万。
  • 边界（红线）：菜菜可干预空间很小 → 我方只做持续研发产品给她（产品是唯一抓手），内容端不投入。
  • 纪律：不因为分销盘子大就分散内容与 AI 资源；价格/库存/选品属于产品侧，不与内容主线混谈。

3. 四类内容系统

每类内容 = 一个系统（目标 → 生产管线 → 原料 → 出口 → 指标）。这是本手册的核心。

3.1 品牌内容系统

项 内容
目标 让"开成高俪"在消费者心智里沉淀一块明确的东西（品牌）
任务 树树干母题、做品牌叙事、把信任资产变内容
信任基座（为何有资格讲） 非遗炮制技艺、真年份、陈化老参、检测、韩宝林解释能力、真实工厂、长白山产地
生产管线 品牌叙事 BN 库（五层学习/三层吸收法）→ 树干母题持续逼问 → 信任资产转成可讲的故事与画面
原料 真实产品/人物/工艺/用户故事（人的真实世界）
出口 精品短视频（慢线）、直播间品牌叙事、品牌种树内容
判断标准 它长不长在我们这棵树上？不长，就不要。
指标 认知验证（用户看完，脑子里关于开成高俪多了一块什么）、品牌词搜索、私域/复购意愿类

树干逼问（持续进行）："开成高俪所有这些故事，最后究竟共同证明了什么？"参考叙事方向候选："时间把参养成，参把人的精力养回来。"当前树干未定，不急着定。

3.2 搜索内容系统

项 内容
目标 覆盖正在主动搜索高丽红参/红参片的人，长期截获（引流＋信任）
特点 高转化（人已经在找）、长尾、必须真实回答
生产管线 搜索型图文管线（一页纸沟通方案＋10题结构模板）：真实产品/操作 → AI 选帧/组织/写文案 → 发布 → 数据复盘
原料 真实需求词（直播评论＋平台搜索词）
出口 抖音图文、小红书图文、视频号图文、知乎/百度系图文
指标 搜索词覆盖、图文曝光/点击/停留、主页访问、搜索来源进房

搜索型图文一页纸方案必须包含：封面标题/副标题/画面处理；真实问题是什么、为何写这个选题；视觉规范；获客指标＋品牌认知验证指标；要发布的搜索词/发布正文/置顶评论；团队分工与状态流。

10 题结构模板（以"高丽老红参如何处理"为例）：为什么硬/不能直接切 → 实际处理方法 → 时间温度如何真实记录 → 不看时间如何判断 → 工具/拿法/下刀位置 → 切到什么程度 → 新手易错与必须停止的时刻 → 剩余存储 → 是否适用于所有状态 → 哪些人不适合及替代选择。

中间列"填写要求"逐题规定：必含哪些事实、必演示哪些动作、哪些数据要实测、哪些不能凭经验估算、答到什么程度算完整、哪里需员工追问。右侧栏：保留韩宝林完整原话；没说清按要求追问；不得替韩宝林补写；没测量写"未测量"。附：对应视频/照片、是否答完整、是否需追问、现场新发现。

3.3 GEO 内容系统（生成式引擎优化）

项 内容
目标 让 AI 搜索引擎在推荐"高丽参哪个好/红参怎么选/高丽参适宜人群"时引用开成高俪（信任＋引流）
背景 用户越来越多直接问 AI 助手（豆包、元宝、Kimi、DeepSeek、秘塔AI搜索、夸克、知乎直答等）。谁的结构化事实内容被这些引擎引用，谁就获得"被推荐"的信任。
生产管线 真实需求词 → 结构化 Q&A 事实内容（带实体/日期/数据）→ 发布到 AI 可抓取的权威源 → 实体一致性 → 监控引用
机制四要素 ① 结构化（Q&A 格式、分点、可摘录）② 事实型（真年份/非遗/检测/产地这些不必撒谎的硬证据）③ 实体一致（开成高俪/高丽老红参/韩宝林/非遗/长白山，全平台同名同述）④ 权威入口（官方账号/官网/公众号/微博等语义源＋知乎高质量回答）
原料 真实 query（"高丽参哪个牌子好"“红参片怎么保存”“高丽参适合什么人吃”等，能写入被引擎抓取的正文）
出口 权威语义源（公众号/微博/官网/企业号）、知乎高质量问答、小红书/抖音（内容源）、百度系
指标 AI 引用/被提及、权威源收录、品牌词关联、AI 中被推荐出现率

GEO 纪律：只写不用撒谎的事实（真假细节、检测、年份、非遗、产地、吃法），靠真实证据被引用；不写夸张营销话术，营销话术恰恰会被 AI 识别并降权。

3.4 千川投放素材系统

项 内容
目标 持续、有效把"可能买开成高俪高丽老红参的人"送进今晚直播间（引流）
最高标准 不是素材好不好看，而是能否持续送对的人进房、跑出可规模化 ROI
生产机制 爆款原点库＋素材ID数据体系＋A/B实验协议（见 v0.1 第 4 章）
黄金对应关系 一个素材ID = 一个视频文件 = 一行/一组投放数据
文件名规范 带素材ID，如 836271_韩宝林_老参开头01.mp4
留档标准 MP4、9:16 竖屏（1080×1920）、保留原声/原字幕、原时长不剪短；上传受限时截 6-10 张关键帧＋口播文案＋数据截图
原料 直播评论（用户原点）＋ 平台爆款（外部原点）＋ 历史数据（已验证原点）＋ 产品/非遗/人物（独有证据）
出口 千川投放 → 直播间进房 → 成交
指标 消耗/展现/点击/CTR/CPC、进房人数/进房成本、平均停留/互动/商品点击、成交人数/订单/金额/ROI、3秒5秒播放/完播

素材数据字段（素材粒度，千川导出什么给什么，不加工）：日期、计划名、素材ID、消耗、展现/点击/CTR/CPM/CPC、直播间进房/进房成本、平均停留/互动/商品点击、成交人数/订单/金额、ROI、成交成本、3秒/5秒播放、完播率、投放设置。

第一步动作：数据体检——现有数据能看出什么、缺什么、以后固定怎么导。跑得好的、跑得差的、花不出去的、点击高但不成交的都要（失败素材有时比爆款更重要）。

4. 内容 → 目标归口矩阵

三大目标（引流/信任/品牌）与四类内容不是一对一的，而是一张内容同时打多个目标，但每类有一个主任务：

内容类型 主任务 一阶目标 二阶目标 沉淀
品牌内容 心智沉淀 品牌 信任 让"开成高俪"成为心智里的一块
搜索内容 覆盖主动搜索者 引流 信任 长期截获在高丽红参需求上的人
GEO 内容 被 AI 引用 信任 引流 建立"权威可信"的语义资产
千川素材 送人进房 引流 — 跑出可复制的爆款原点

一条内容最终要回答：开成高俪每天新增的客户，到底是被什么内容带进来的？（见第 7 节漏斗）

5. 分工与 Content OS

  • AI-first：每个工作节点先问"我能不能直接完成"——能就完成；不能但能调工具就调工具；工具不够就研究接入；都不行才交给人。人的位置越来越少。
  • 分工边界：真实世界（韩宝林出镜/拿参/展示工艺/真实经验＋摄影采集）→ 进入数字世界后尽量全归 AI。
  • 内容主线：单产品聚焦，不做多线。所有内容都长在同一棵树（高丽老红参/开成高俪/韩宝林）上。
  • 审阅闭环：分层审阅，只审关键环节（如前三秒钩子），二值决策（通过/不通过），快速过闸。
  • 自动化原则：先磨流程、跑顺几轮再自动化；不把错误的采集/生产方法自动化。

6. 原料管线（从真实出发）

所有内容都发源于真实，不闭门造车。现有原料：

  1. 真实直播评论（44 条，飞书数据/评论记录_20260821.csv） → 这是真实需求词库：提炼用户为什么进来、担心什么、想解决什么、为什么不买、买给谁、怎么吃。直接喂：
    - 搜索内容（真实 query 词）
    - GEO 内容（真实问题→结构化回答）
    - 千川素材（"用户原点"矿）
    - 场景库（什么人/什么时间/什么状态→获客场景）
  2. 真实产品/人物/工艺（韩宝林、非遗、真年份、陈化、检测、长白山）→ 品牌内容＋信任资产。
  3. 真实投放数据（千川导出）→ 千川素材数据体检与原点验证。

需求词分类表（每条评论归类）：真假类 / 年份类 / 硫磺加工类 / 上火类 / 方便类 / 价格类 / 品牌比较类 / 其他。

7. 指标体系

漏斗（内容 → 商业）：内容曝光 → 播放/3秒/完播 → 主页访问 → 粉丝 → 直播间进入/进房成本 → 商品点击 → 成交 → 复购 → 新客成本/新客GMV。

  • 只爆播放、不进直播间的内容，价值等级下降。
  • 每条内容最终要回答：开成高俪每天新增的客户，到底是被什么内容带进来的？

四类内容各自指标见第 3 节对应表格。全局红线（D1）：建不了明确认知的选题不做；有流量但沉淀不了认知的不盲目放大；发布后必须复盘认知是否建立、失败在哪一环；每条内容同时是用户研究、产品验证和品牌进化。

8. 第一阶段 30 天执行计划（单产品版）

周 直营主线（高丽老红参）

第 2 周 首批搜索内容＋GEO 内容上线（结构化事实型、实体一致）；首个爆款原点候选入库；7池系统按每日评论分流试运行
第 3 周 品牌叙事 BN 库继续喂料、树干逼问持续推进；千川素材按素材ID数据体系开始打磨第一批；搜索/GEO/千川三线数据复盘

分工：用户＝商业判断＋投喂真实材料＋校准；我（AI）＝吸收→判断→产出（内容方案/素材/复盘迭代）；韩宝林＝真实世界出镜与真实经验；菜菜＝只接产品。
