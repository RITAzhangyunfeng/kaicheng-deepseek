一、产品主线（一参正气草本饮）

产品定位：开成高俪"一参正气草本饮"。以市级非遗高丽参（红参）为基底，针对不同体质配伍其它道地同源草本，做成便携饮品。一盒30支，一支10ml（塑料袋装/小袋装）。

1. 三种配方（主产品线）

三种配方的原料（来自"调教ai脚本概况.txt"主口径），经核对：三种配方去重后恰好 20 味原料 → 对得上"20味道地原料"这一卖点。

- 方2 西洋参黄芪草本饮（绿色包装）↔ 阴虚方/气阴两虚
- 方3 红参肉桂山药草本饮（橙色包装）↔ 阳虚方/阳气亏虚

2. 工艺流程

精准称料 → 20倍水提（释放原材有效成分）→ 离心（去杂质，口感细腻）→ 17倍低温浓缩（锁鲜、保留纯粹）→ 灌装 → 灭菌。
附加卖点中另有"5小时鲜制"。

3. 主要卖点

非遗老参为基底、20味道地原料、工艺、科学配伍、产品形态（便携小袋）、无需自己搭配配方、口感、5小时鲜制、便携、温和。

4. 目标人群

  • 虚不受补（很虚不敢补、吃点就上火）
  • 亏气血、阴虚、阳虚
  • 怕传统滋补方式麻烦
  • 上班白领（想随时随地补充能量）
  • 需要调养的中老年人

四、与"高丽老红参"品牌的关系

  • 品牌：開成高儷® / 开成高俪（1994）。生产企业：吉林省天壹参草中药饮片有限公司（地址：临江市桦树镇森铁社区）。
